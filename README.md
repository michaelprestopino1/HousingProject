# This repository contains my specific contributions to a group project analyzing the factors that affect U.S. housing prices.

My Contribution
Master Data Merging: The script in MergingCode.ipynb combines Census, Zillow Home Value (ZHVI), and WARN layoff data into a single clean dataset (master_clean.csv) for the team.
FEMA Data Integration & Analysis:
The script in mprestopino_cleaning_joining_code.ipynb adds FEMA disaster declaration data to the master dataset.
The notebook mprestopino_analysis.ipynb contains my exploratory data analysis and regression modeling based on this final combined dataset.
